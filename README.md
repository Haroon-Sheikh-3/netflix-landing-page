# Netflix Landing Page Clone

A responsive front-end recreation of the Netflix landing page interface.

## 🚀 Features

- Fully responsive layout across mobile, tablet, and desktop
- Modern flexbox & grid structure
- Accordion-style FAQ section

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox/Grid)

## 💻 How to Run

Simply clone the repository and open `index.html` in your browser.

This is a front-end practice project focused on responsive design and visual replication using only HTML and CSS. No JavaScript framework or runtime is used.

## 📝 Purpose

Built as a frontend exercise in building a responsive, visually deliberate landing page. Semantic HTML and CSS match the layout and responsive behavior of a modern streaming landing page without relying on a framework.
